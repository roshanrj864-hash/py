## Computer Lab Access System

This Python program checks whether a student is allowed to enter the computer laboratory.

A student receives access only when:

1. The student is registered for today's lab.
2. The computer laboratory is open.
3. A computer is available.

## Files

- `main.py` integrates and runs the program.
- `student.py` collects student information.
- `access.py` checks the access conditions.
- `display.py` displays the final result.

## Run the Program

```bash
python main.py
